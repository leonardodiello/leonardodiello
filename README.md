## Projetos em destaque

### API de Filmes

Aplicação web desenvolvida com **Python e Flask** para consulta de filmes através da OMDb API.

O projeto trabalha com requisições HTTP, consumo e tratamento de dados JSON, variáveis de ambiente e apresentação das informações em uma interface web.

**Tecnologias:** Python, Flask, Requests, HTML, CSS, Jinja2 e OMDb API.

[Ver projeto](https://github.com/leonardodiello/API_filme) · [Aplicação online](https://api-filme-1hka.onrender.com/)

---

### CRUD Python + MySQL

Aplicação web desenvolvida com **Python, Flask e MySQL**, implementando as operações de criação, consulta, atualização e exclusão de registros.

O projeto também envolve integração com banco de dados, formulários HTML, templates Jinja2 e utilização de variáveis de ambiente.

**Tecnologias:** Python, Flask, MySQL, HTML, CSS e Jinja2.

[Ver projeto](https://github.com/leonardodiello/CRUD_Python)

---

### Chatbot de Turismo

Chatbot desenvolvido em Python durante um curso do Samsung Ocean, com integração ao Telegram e processamento de linguagem natural.

O projeto utiliza **TF-IDF e similaridade por cosseno** para identificar a intenção das mensagens e retornar informações relacionadas a atrações turísticas.

**Tecnologias:** Python, Pandas, NLTK, Scikit-learn, Telegram Bot API e python-dotenv.

[Ver projeto](https://github.com/leonardodiello/Chatbot_turismo)

**Status:** Em melhoria.

---

### CRUD com SQLite

Projeto desenvolvido para praticar operações CRUD utilizando **Python e SQLite**, trabalhando diretamente com criação de tabelas, inserção, consulta, atualização e exclusão de registros.

Também utiliza variáveis de ambiente para configuração do banco de dados.

**Tecnologias:** Python, SQLite e python-dotenv.

[Ver projeto](https://github.com/leonardodiello/CRUD_SQLite)

### WeatherAPI

Aplicação desenvolvida em Python para consumo de uma API de previsão do tempo.

**Tecnologias:** Python, Streamlit e API REST.
